# 🐷 حصالة محمود

تطبيق ويب تقدمي (PWA) لتتبع المهام اليومية للأطفال. كل يوم يعلّم محمود على المهام التي أنجزها فيكسب نقاطًا، وكل نقطة لها قيمة بالجنيه المصري. تظهر حصالة تفاعلية تعرض المبلغ المتجمع وينطق التطبيق المبلغ بصوت عربي.

## ✨ المميزات

- 📋 قائمة مهام يومية قابلة للتخصيص (١٠ مهام افتراضية)
- 🐷 حصالة تفاعلية تعرض الرصيد المتجمع مع حركات ممتعة
- 🔊 نطق المبلغ بالعربية المصرية عند كل إنجاز
- 📅 سجل يومي مع تقويم شهري ملوّن
- 🔥 سلسلة الأيام المتتالية
- 🔒 إعدادات محمية برمز سري (PIN) للأب
- 💰 سحب مبالغ من الحصالة مع تسجيل السبب
- 📱 يعمل كتطبيق على الموبايل (PWA)
- 📴 يعمل بدون إنترنت بعد أول تحميل
- 🎉 احتفال عند إنجاز كل مهام اليوم

## 🚀 التشغيل المحلي

```bash
npm install
npm run dev
```

## 🔨 البناء

```bash
npm run build
```

## 🧪 الاختبارات

```bash
npm run test
```

## 🛠️ التقنيات

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS** للتنسيق
- **Zustand** مع `persist` لإدارة الحالة وحفظها في `localStorage`
- **vite-plugin-pwa** للعمل بدون إنترنت
- **Web Speech API** للنطق الصوتي
- **خط Cairo** (مُضمَّن محليًا عبر `@fontsource/cairo`)

## 📝 ملاحظات

- كل البيانات تُحفظ محليًا على الجهاز (لا يوجد سيرفر)
- عند تغيير قيمة النقطة، لا يتأثر المبلغ التاريخي المكتسب
- الأموال تُخزَّن داخليًا بالقروش (أعداد صحيحة) لتفادي أخطاء الفاصلة العشرية
- الرمز السري يُخزَّن مجزّأ (SHA-256) ولا يُخزَّن كنص صريح
